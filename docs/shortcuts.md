# Everything you can type, and every key

Back to the [README](../README.md).

## Type this, get that

Type the symbol at the **start of a line**, then a space. The symbol disappears
and the line changes.

| Type… | …and get |
|---|---|
| `- ` / `* ` / `+ ` | a bullet list |
| `1. ` / `1) ` | a numbered list |
| `[] ` / `[ ] ` / `- [] ` | a checkbox |
| `# ` … `###### ` | headings, six sizes |
| `> ` | a quote |
| `[!note]` `[!tip]` `[!important]` `[!warning]` `[!caution]` then Enter | a coloured box (with or without a `> ` in front) |
| ` ``` ` then Enter | a code block. ` ```js ` keeps the language |
| `---` / `***` then space or Enter | a line across the page (must be the whole line) |

In the middle of a sentence, these close themselves as you type:

| Type… | …and get |
|---|---|
| `**text**` | **bold** |
| `*text*` | *italic* |
| `` `text` `` | `code` |
| `~~text~~` | crossed out |
| `==text==` | highlighted |
| any web address, then space or Enter | a link (a trailing `)` or `.` stays plain) |

Triggers work anywhere — on the first line of an empty note, and on lines that
already have words after the cursor.

## Keys

| Key | What it does |
|---|---|
| `Ctrl+Z` / `Ctrl+Shift+Z` (or `Ctrl+Y`) | undo / redo |
| `Ctrl+B` / `Ctrl+I` / `Ctrl+U` | bold / italic / underline |
| `Ctrl+Shift+X` | crossed out |
| `Ctrl+E` | code inside a sentence |
| `Ctrl+Shift+E` | code block (press again to go back) |
| `Ctrl+Shift+7` / `Ctrl+Shift+8` / `Ctrl+Shift+9` | numbered / bullet / checkbox list |
| `Ctrl+Alt+0`–`Ctrl+Alt+3` | plain line / heading 1–3 |
| `Alt+Shift+↑` / `Alt+Shift+↓` | move this block up / down |
| `Ctrl+\` | strip the formatting off |
| `Ctrl+K` | add or edit a link |
| `Ctrl+F` | find and replace |
| `Ctrl+S` | back up now |
| `Ctrl+Alt+N` | new note |
| `Ctrl+Shift+F` | zen mode — hide everything but the words |
| `Ctrl+Enter` | get out of a code block, quote or list |
| `Tab` / `Shift+Tab` | move a list item, or a code line, in and out |
| `/` | jump to the note search |
| `Esc` | close whatever is open; leave zen mode |

On a Mac, use `Cmd` wherever this says `Ctrl`.

## Pictures

Paste a picture in, or use the picture button in the toolbar. Then **click the
picture**:

- the four **corner handles** drag it bigger and smaller;
- **Sits** decides where it goes — *Inline* puts it in the run of your words,
  *Left* / *Center* / *Right* give it a line of its own, and *Wrap left* /
  *Wrap right* push it to one side with the text flowing around it;
- **Size** sets it to a quarter, half, three quarters or the full width of the
  line, and *Original* puts it back to the picture's own size;
- **Alt text** is the description screen readers read out;
- **Remove**, or the `Delete` key, takes it out.

Size and placement survive the trip out to Markdown and back, so a note that
syncs to Drive comes back looking the way you left it.

## Links

Typewell follows the same rule as Word and Google Docs, because you are
*editing* the page, not reading it:

- a **plain click** puts the cursor in the link so you can edit it, and pops up
  a small bar with open / edit / copy / unlink;
- **Ctrl+click** (Cmd+click on a Mac) opens the link in a new tab.
